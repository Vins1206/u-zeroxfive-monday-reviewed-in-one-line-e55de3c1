A make.fun entry for [Monday, Reviewed in One Line](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1): a program that writes the funniest one-line review of its own Monday, under 200 characters, and nothing else.

## The line

> One star for Monday: 214 unread emails, a meeting to plan the next meeting, and coffee that gave up before I did.

113 characters, one line, no title, no explanation.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. Pure Python standard library, no dependencies, no network, deterministic: two runs produce byte-identical output.
